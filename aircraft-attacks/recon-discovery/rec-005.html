BS-REC-005: Physical Infrastructure & Location Recon

Mapping physical access points, hangars, and external cable panels using geospatial intelligence.

Technique Description

📍 Physical / OSINT

Adversaries map the physical environments where the target aircraft operates. This includes identifying specific parking stands, maintenance hangars, and external avionics access panels (e.g., external data ports). Intelligence is gathered remotely using geospatial tools like Google Earth, satellite imagery, or open-source airport layout diagrams to plan for physical intrusion or localized hardware attacks.

Targeted Systems: External Data Loaders, Avionics Compartments, Hangar Networks.
