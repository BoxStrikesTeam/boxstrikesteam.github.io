BS-DIS-004: ADS-B Signal Interception & Airspace Enumeration

Capturing, decoding, and analyzing 1090 MHz Mode S/ADS-B signals using SDR to map airborne targets and extract real-time telemetry.

Technique Description

📡 RF / Physical

Adversaries utilize Software Defined Radio (SDR) hardware, such as RTL-SDR, connected to a computing device with an appropriately placed antenna to intercept aviation telemetry. After installing and compiling the necessary decoding software (e.g., dump1090), the attacker initiates the capture process on the 1090 MHz frequency. The adversary then continuously monitors the data stream. By extracting structured JSON outputs or saving raw data packets for deeper offline inspection, the attacker successfully enumerates aircraft identities (ICAO 24-bit addresses, flight numbers), real-time telemetry (altitude, speed, heading), and operational patterns within the target airspace.

Targeted Systems: ADS-B Out Transponders (1090ES), RTL-SDR Hardware, Decoding Software (dump1090, piaware, ModeSBeast).
Box Strike Note: This technique requires zero authentication or initial access to the aircraft. It is a purely passive discovery method that exploits the inherent lack of encryption and cryptographic authentication in the ADS-B protocol, serving as the foundational step for subsequent spoofing or ghost aircraft injection attacks.
