BS-DIS-002: System Component & Vulnerability Scanning

Identifying operating systems, firmware versions, and known CVEs within the accessed aviation network.

Technique Description

🟡 Local Network

Following network enumeration, the adversary actively scans the compromised environment to identify specific software and hardware details. This includes determining the operating systems of cabin servers, firmware versions of networking equipment, and checking for known vulnerabilities (CVEs). By combining active port scanning with OSINT regarding specific aviation hardware, the attacker maps out exploitable weaknesses to achieve execution or privilege escalation.

Targeted Systems: IFE Servers, EFB Tablets, Avionics Gateways, Network Switches.
